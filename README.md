# affordablehorns.no

Standalone Astro site for Affordable Horns, extracted from the Affordable Horns content on tormoen.no.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run check
npm run build
npm run preview
```

## Vercel

Import this repository into Vercel with these settings:

- Framework preset: Astro
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

The site is configured for `https://affordablehorns.no` in `astro.config.mjs`.
